# MISC

`misc/` is a temporary workspace for bounded experiments, short-lived roadmaps, and insights that are useful enough to preserve but are not yet canonical Spotwo architecture or company strategy.

Rules:

- content here is intentionally non-authoritative;
- an experiment in `misc/` does not create a runtime dependency or product commitment;
- a temporary roadmap is a snapshot of current thinking, not the company roadmap;
- when an insight becomes durable, promote it into the appropriate canonical area such as `decisions/`, `kernel/`, `ontology/`, `operations/`, or a dedicated production-grade lab;
- preserve evidence and failed experiments instead of silently rewriting history.

Current contents:

- `roadmap/2026-08-19-small-roadmap.md` - a seven-step temporary engineering roadmap captured from the current repository work;
- `api-contract-lab/` - an isolated REST/OpenAPI versus gRPC contract experiment.
