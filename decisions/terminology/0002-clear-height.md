# 0002 - Clear Height terminology

Status: Proposed
Date: 2026-08-18

## Context

Spotwo needs a stable name for the unobstructed usable vertical warehouse dimension. Current industrial-property listings from Prologis, CBRE, SEGRO and GLP use `Clear Height` across North American and European markets.

## Decision

Use `Clear Height` as the candidate Spotwo UI and domain term.

Do not yet treat the repository definition as a normative engineering measurement rule. The exact measurement boundary must be mapped to the applicable architectural, fire-safety, and racking standards before using this value for automated compliance or engineering calculations.

## Consequences

- Product UI can converge on `Clear Height`.
- Aliases remain searchable.
- Engineering validation remains intentionally unresolved until standards mapping is complete.
