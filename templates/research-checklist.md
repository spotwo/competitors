# Competitor Research Checklist

Use this checklist when adding or refreshing a vendor. Unknowns should become explicit `research_gaps`; never guess to make a record look complete.

## Identity and ownership

- Canonical vendor name and website
- Current parent company / acquisitions / rebrands
- Former product and company names
- Headquarters country, only when evidenced

## Market and commercial position

- Regions and countries served
- Local offices / implementation / support presence
- SMB, mid-market, enterprise positioning
- Warehouse complexity or edition segmentation
- Industries and operating environments
- Pricing or commercial model when public

## Product portfolio

- WMS / WES / WCS / MFS / ERP / OMS / TMS / YMS / LMS / MES / CMMS layers
- Product names and editions
- SaaS / cloud / on-premise / hybrid deployment
- Mobile, browser, handheld, voice and wearable clients
- API, EDI, ERP and automation integrations

## Warehouse process coverage

- Receiving and inspection
- Putaway and cross-docking
- Storage, relocation, slotting and replenishment
- Cycle count and physical inventory
- Allocation, wave / waveless release and task management
- Picking, consolidation, packing and sortation
- Staging, loading and shipping
- Returns / reverse logistics
- Labor, yard and 3PL billing

## Domain model and terminology

- Warehouse / site / building / zone / area
- Aisle / bay / rack / shelf / level / bin / location
- Dock / dock door / staging lane
- Item / SKU / lot / batch / serial number
- Container / handling unit / LPN / pallet / tote / carton
- Order / wave / work / task / warehouse order
- Inventory status, ownership and reservation concepts
- Units of measure and dimensional terminology

## Automation

- WES orchestration model
- WCS / MFS boundaries
- PLC / machine-control boundary
- AS/RS, conveyors, sorters, AMR/AGV, pick-to-light, put-to-light, voice
- Multi-vendor robot orchestration
- Simulation / digital twin / control tower

## UX and operations

- Operator workflows and terminology shown in UI
- Scanner / mobile screens
- Supervisor dashboards
- Exception handling
- Configuration model
- Role and permission model
- KPI names and definitions

## Evidence quality

- Prefer official documentation or standards
- Capture exact source URL and date
- Separate vendor marketing claims from observed product facts
- Add one claim per important reusable fact
- Record contradictory sources instead of silently choosing one
- Re-check time-sensitive claims and mark superseded claims explicitly
